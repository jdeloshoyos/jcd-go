JCD - Terminal Directory Navigator
==================================

Install on Windows

1. Extract this ZIP to a folder.
2. Open PowerShell in that folder.
3. Run the installer:

       powershell -ExecutionPolicy Bypass -File .\install.ps1

   The Bypass switch is required because Windows blocks unsigned scripts
   that were downloaded from the internet.

4. Start a new PowerShell window.
5. Run:

       jcd

The installer sets everything up for your user account only (no
administrator rights needed). It is safe to run again to upgrade and
keeps your configuration and history.

Full documentation: https://github.com/jdeloshoyos/jcd-go
